# North Star Bakery Touchstone 4

This continues the existing four-page North Star Bakery website.

Upload the contents of this folder to your existing project, preserving the Bakery_c folder and file names. Start your IDE preview server and add its working link to the Word document before submitting. The Word document is the single assignment submission; the linked project must contain these updated website files.

Products: save favorites, prevent duplicates, clear the list, and restore favorites after refresh.
Contact: validate name, email, request type, item details, and pickup date for pre-orders. Valid entries save name and email for a later visit. This is a client-side classroom demo and does not send requests to a server.

Test on an HTTP preview, rather than opening files directly, so browser storage has a consistent origin. The two localStorage keys are northStarBakeryFavorites and northStarBakeryCustomer.

Before submitting, verify that your preview and repository are accessible to the grader and contain this version. Link-related checklist items remain unchecked in the document until you complete that step.
